Interaktive R-Shiny-Anwendung zur Bewertung festverzinslicher Wertpapiere und zur Simulation von Anleiheportfolios.

Die erste Version bietet zwei Arbeitsbereiche: „Anleihebewertung“ und „Portfoliosimulation“. 

Funktionen: Bewertung festverzinslicher plain vanilla bonds

Einschränkungen:
V_1 unterstützt nicht:

Variabel verzinsliche Anleihen
Kündbare Anleihen
OAS
Kreditspread-Modelle
Konstruktion von Zinskurven
Key-Rate-Duration
